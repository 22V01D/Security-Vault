# Web Security Notes & Journey

Here is my personal repository of documentation on web security! It includes the structured notes, learnings, and practical insights that I have acquired as I investigate the field of web application security.

## Purpose

This repository aims to function as a dynamic knowledge base documenting my experiences in the field of web security. It includes information on different vulnerabilities, attack methods, defence measures, and the real-world techniques that I have both studied and put into practice. I have prepared these notes in order to reinforce my own understanding and to offer a rapid reference for various concepts, payloads, and methodologies.

## How to Use These Notes

Note: It is intended that these notes should be used in conjunction with **[PortSwigger Web Security Academy](https://portswigger.net/web-security)**. For an optimal learning experience, it is strongly advised that you carry out the relevant PortSwigger labs as you go through each topic. The practical and hands-on method employed by PortSwigger Academy matches ideally with the theoretical and payload-focused notes provided here.
